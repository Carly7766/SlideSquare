# 企画書
## ボードを動かすボードゲーム

## 1. 概要

5×5マスの盤面で行う2人対戦ボードゲーム。

各ターン、プレイヤーは**自分の駒を1マス移動**させたあと、**盤面の横一列をスライド**させる。駒だけでなく盤面そのものを操作できる点が本作の特徴。

**勝利条件**: 相手の駒をすべて取る、または自分の駒を自分のゴールマスに到達させる。

---

## 2. 盤面と駒

盤面は5×5（25マス）。駒は2種類、各プレイヤー5個。

| 種類 | 移動方向 | 個数 |
|---|---|---:|
| 上下左右移動の駒 | 上下左右のいずれかに1マス | 2 |
| 斜め移動の駒 | 斜め4方向のいずれかに1マス | 3 |

---

## 3. 初期配置

上側プレイヤー = A、下側プレイヤー = B。「斜」= 斜め移動の駒、「直」= 上下左右移動の駒。

|   | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | A斜 | ・ | A斜 | ・ | A斜 |
| 2 | ・ | A直 | ・ | A直 | ・ |
| 3 | ・ | ・ | ・ | ・ | ・ |
| 4 | ・ | B直 | ・ | B直 | ・ |
| 5 | B斜 | ・ | B斜 | ・ | B斜 |

---

## 4. ターンの流れ

先手は開始時にランダムに決定する。**先手のみ、最初のターンはスライドを行わない**（先手有利の補正）。

1. **ターン開始判定** — 自分の駒が自分のゴールマスにある（定着）、または同一局面が3回目なら決着
2. 自分の駒を1つ移動（5章）
3. **移動直後判定** — 自分のゴールマスに入った、または相手を全滅させたら勝利
4. 未決着なら盤面をスライド（6章。スライド直後は判定しない）
5. 相手のターンへ

自分の駒に合法な移動が1つもない場合（すべての駒が盤外・自分の駒に阻まれている場合）は、移動・スライドとも行わずそのターンをパスし、相手のターンへ移行する。移動連動スライド（6章）は今行った移動を前提とするため、移動できない以上スライドも成立しない。

---

## 5. 移動ルール

駒はそれぞれの移動方向へ1マス移動できる。

- 盤外へは移動できない
- 自分の駒があるマスへは移動できない
- 相手の駒があるマスへは移動できる（その駒を取る）

---

## 6. スライドルール

盤面の横一列を左右どちらかへ1マス分スライドさせる。端から押し出された駒は反対側へ回り込む。スライドでは駒は取れない。

選べる列には3つの制限がある。

1. **移動連動** — 今動かした駒の「元いた列」か「移動先の列」しか選べない
2. **空列禁止** — 駒が1つもない列は選べない
3. **巻き戻し禁止** — 相手が直前にスライドした列を、直後の自分の番で逆方向に戻すことはできない（同方向へはさらに進められる）

「移動先の列」には必ず今動かした駒があるため制限2に触れず、制限3で塞がれても反対方向は残るため、選べるスライドが0になることはない。

---

## 7. 勝利条件

1. **全滅** — 相手の駒をすべて取る
2. **ゴール到達** — 自分のゴールマス（自分から見て左下角）に自分の駒を置く
   - 移動で到達 → **即時勝利**
   - スライドで到達 → **定着**：次の自分のターン開始時までその駒が残っていれば勝利。相手は取るか、同じ列を同方向へ押し出すことで阻止できる
3. **千日手** — 同一局面（手番含む）が3回出現したら引き分け。再戦時は先後を交代する

| プレイヤー | ゴールマス |
|---|---|
| A（上側） | 5行目・1列目 |
| B（下側） | 1行目・5列目 |

ゴールマスは色（青/赤）と★マークで視覚的に示す。

---

## 8. 仕様まとめ

| 項目 | 内容 |
|---|---|
| 盤面 | 5×5 |
| 駒 | 各プレイヤー5個（斜め移動3・直進2） |
| 先手 | ランダム決定。初手はスライドなし |
| ターン | 開始判定 → 移動 → 移動後判定 → スライド → 相手ターン |
| スライド | 横一列、左右1マス、端は反対側へ回り込む |
| スライド制限 | 移動連動 / 空列禁止 / 巻き戻し禁止 |
| 勝利条件 | 全滅、ゴール到達（即時到達/定着）、千日手で引き分け |
| 合法手なし | 動かせる駒が1つもない場合、移動・スライドともパスして相手のターンへ |

---

## 9. 調整ルールの意図（要約）

| ルール | 狙い |
|---|---|
| 定着ルール | スライドでの到達に1ターンの反撃機会を挟み、単純なレース化を防ぐ |
| 巻き戻し禁止 | スライドの打ち消し合いによる膠着を防ぐ |
| 空列禁止 | スライドが実質的なパスになるのを防ぐ |
| 移動連動スライド | 移動とスライドを連動させ、無関係な列で時間を稼ぐ"待ち"と将棋的な静的さを防ぐ |
| 先手初手スライドなし | 対称な配置でも先手が構造的に有利になる問題を補正する |
| 千日手 | 決着がつかない対局を打ち切る安全弁 |

各ルールの詳しい経緯・検討過程は `DesignRationale.md` を参照。今後の検討案（縦列スライド、持ち駒、ゴール複数化など）も同ファイルにまとめてある。
