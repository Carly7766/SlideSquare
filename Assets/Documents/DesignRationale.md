# 設計背景メモ

GameDesign.md の各調整ルールがなぜ導入されたかの詳細な経緯・分析。企画書本体を簡潔に保つため、ここに退避してある。ルールそのものの正は GameDesign.md を参照。

---

## 1. ゲーム木が単純化する要因

1ターンの選択肢の数そのものは、駒の移動が最大16通り前後、スライドが10通りと十分にあるように見える。しかし、実際の読み合いは以下の理由で浅くなる。

1. **スライドが完全に可逆である**
   スライドは駒を取らず、必ず1マスであるため、相手のスライドは同じ列を逆方向へスライドすれば完全に打ち消せる。互いに最善を尽くすと「スライドの打ち消し合い」に収束し、局面が一切進まなくなる。

2. **単一の必勝パターンへの縮退**
   ゴールは相手陣最奥の横列の隅にあり、スライドは横方向のみ、さらに端の駒は反対側へ回り込むため、同じ横列内でのゴールまでの距離は最大でも2マスしかない。このため「駒を1つ相手陣最奥の列まで送り込み、スライドで毎ターンゴールへ寄せる」ことが支配的な戦略になる。スライドで乗った瞬間に勝ちが確定するルールでは、守る側の対抗手段は寄せてくる駒を取ることしかなく、ゲーム全体が「どちらが先に相手陣最奥の列へ駒を到達させるか」という単純なレースに縮退する。

3. **空の列のスライドが「パス」になる**
   駒のない列（開始時の3行目など）をスライドしても盤面は変化しない。スライドが必ず行う行動であることの緊張感が失われる。

4. **移動とスライドが独立した手として処理される**
   スライドは移動とは無関係にどの列でも選べるため、盤面操作が「今の一手」の結果ではなく、手番全体から自由に選べる独立した行動になってしまう。局面全体を見て最も無難な列を選び続ける"待ち"の展開が可能になり、将棋的な静的な読み合いに近づいて、大きな形勢逆転が起こりにくくなる。

## 2. 先手有利の構造

初期配置とゴールの位置は点対称であり、両者の条件は完全に対等である。しかし前述の通りゲームがレースに縮退するため、移動とスライドを1手早く始められる先手が、同じ速度のレースを必ず制する。勝利判定は行動したプレイヤーのターン中に行われるため、両者が同じターン数でゴールに届く展開でも必ず先手が先に判定を受ける。つまり、構造的に先手が有利である。

## 3. 調整ルールと狙い

検討の過程で、単純な組み合わせには落とし穴があることも分かった。巻き戻し禁止（コウ）は膠着を防ぐ一方で、守り側の「スライドを元に戻す」対応まで禁止してしまうため、これだけではスライドによるゴール寄せを捕獲以外で止められなくなり、かえってレースを鋭くする。そこで本作では、レースの問題をスライドの制限ではなく**勝利条件の側**（定着ルール）で解決する。

| 調整ルール | 対応する問題 | 狙い |
|---|---|---|
| ゴールの定着ルール | レースへの縮退 | スライドによる到達に必ず1ターンの反撃機会を挟み、「乗せる・取る・押し出す」の攻防を作る |
| 移動による即時到達 | — | 進入マスを守る側と、スライドで守りをずらしてこじ開ける側の駆け引きを作る |
| 相手の直前のスライドの巻き戻し禁止 | スライドの可逆性 | 打ち消し合いの膠着を防ぐ。守り側には同方向への「押し出し」が常に残るため、防御は失われない |
| 空の列のスライド禁止 | 実質パス | スライドを常に盤面が変化する行動にし、動かしたくない局面でも選択を迫る |
| 移動連動スライド | 移動とスライドの独立化 | スライドできる列を今動かした駒の列に限定し、盤面操作を「今の一手」の結果として意味づける。無関係な列で時間を稼ぐ"待ち"を封じ、移動先の選び方がそのままスライドの選択肢を左右する連鎖的な仕掛けを誘発する |
| 先手の第1ターンはスライド禁止 | 先手有利 | 先手の初速を移動のみに抑え、実質的な行動数の差を縮める |
| 千日手は引き分け | 無限ループ | 決着がつかないゲームを打ち切る安全弁。再戦時の先手後手交代とあわせて公平性を保つ |

移動連動スライドを導入したことで、巻き戻し禁止が機能する場面（＝直前の相手のスライドと同じ列を、自分も動かせる場面）はかなり限定される。両ルールは矛盾しないため併用しているが、巻き戻し禁止の実効性が薄れていないかはプレイテストで検証し、不要と分かれば整理する。

定着ルールの下では、スライドでゴールマスに駒を乗せても、相手には必ず1ターンの反撃機会がある。相手はその駒を取るか、同じ列を**同方向**へスライドして駒をゴールマスから押し出せる（同方向のスライドは巻き戻しに当たらないため、常に合法である）。この「乗せる→押し出す」の応酬を単純に繰り返すだけでは千日手の引き分けに収束するため、攻め側は複数の駒で同時に脅威を作るなどして、相手の反撃そのものを咎める形を用意する必要がある。ここに本作の中心的な読み合いが生まれる。

## 4. 不採用とした案

- **移動させた駒がいる列のスライド禁止**: 「移動＋スライドで1ターンに2マス寄せる」ことへの対策として検討したが、定着ルールによってスライド到達自体が即勝利でなくなったため、この形（＝動かした列を**禁止**する）では不要と判断した。ただし、静的な展開を防ぐという別の目的で、後に逆方向の制約（＝動かした列に**限定**する、移動連動スライド）を採用している。禁止と限定は逆向きの制約であり、解決したい問題も異なる点に注意。
- **パイルール（先手の初手を見てから後手が立場を選ぶ方式）**: 先手補正として有力だが、初見プレイヤーへの説明コストが高いため、まずはシンプルな「先手の第1ターンはスライド禁止」を採用する。プレイテストで補正が不足または過剰と分かった場合の差し替え候補とする。

## 5. 今後の検討案

- **縦列スライドの解禁**（保留）: スライドの対象を横列だけでなく縦列にも広げる。選択肢が倍増し、前後方向の駆け引きも生まれる一方、以下2つのリスクがあり要検証。
  - **到達が速すぎる**: ゴールマスは盤面の角（行と列の交点）にあるため、現状は行方向のスライドでしか寄せられない。列スライドまで解禁すると寄せの経路が2本に増え、10章で解決した「単一の必勝パターンへの縮退」が経路を増やす形で再燃する懸念がある。
  - **膠着（2軸のせめぎ合い）**: ゴールマスが行・列の両方からスライドで狙えるようになると、守る側も行方向・列方向の2つの押し出し手段を持つことになる。移動連動・巻き戻し禁止のようなブレーキを列スライドにも同様に用意しないと、行と列を交互に使って無限に押し合える膠着が今より起きやすくなる可能性がある。
  - 単純に横スライドのルールを縦にもコピーするだけでは不十分で、ゴールマスの角（行と列が交差する点）を2軸から同時に攻められる特別な状況として個別に設計し直す必要がある、というのが現時点の結論。
- **取った駒の再投入（持ち駒）**: 取った相手の駒を自分の駒として空きマスに置けるようにする。駒取りの価値が上がり、勝利条件1（全滅）が意味を持ちやすくなる。
- **ゴールマスの複数化・変動化**: ゴールを2か所にする、または条件によって位置が変わるようにすることで、守りの一点集中を崩す。
